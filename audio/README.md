# Audios de palmas

Coloca aquí tus loops WAV con estos nombres:

```text
palmas-rumba-100.wav
palmas-tangos-188.wav
palmas-bulerias-90.wav
palmas-alegrias-80.wav
palmas-sevillanas-150.wav
palmas-fandangos-142.wav
```

La app intentará usarlos cuando el selector de sonido esté en `Palmas`.
Si un archivo no existe, usará automáticamente las palmas generadas con Web Audio.

No subas loops de librerías comerciales a un repositorio público si la licencia no permite redistribuirlos.
